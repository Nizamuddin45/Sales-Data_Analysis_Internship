# Sales Data Analysis Internship Project

## Project Title
Sales Data Analysis using Python (Pandas & Matplotlib)

## Objective
Analyze a synthetic sales dataset (200 rows) to extract business insights such as:
- Total revenue
- Average order value
- Top products by revenue
- Region-wise and category-wise sales
- Monthly sales trends
- Visualizations (bar chart, pie chart)

## Technologies Used
- Python 3.12
- Pandas
- Matplotlib
- Jupyter Notebook
